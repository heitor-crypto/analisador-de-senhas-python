# 🔐 Analisador de Senhas em Python

Este é um projeto que desenvolvi para praticar Python e aprender um pouco mais sobre lógica de programação e segurança digital.

O programa analisa algumas características de uma senha e apresenta uma pontuação de 0 a 100.

## 💻 Como funciona?

O analisador verifica cinco critérios:

- Pelo menos 12 caracteres
- Presença de números
- Letras maiúsculas
- Letras minúsculas
- Símbolos especiais

Cada critério vale 20 pontos.

## 🛠️ Tecnologias utilizadas

- Python 3
- Visual Studio Code

## ▶️ Como executar

1. Baixe o arquivo `analisador_de_senhas.py`.
2. Tenha o Python instalado no computador.
3. Execute o arquivo pelo terminal ou VS Code.
4. Digite uma senha fictícia para visualizar a análise.

## 📚 O que aprendi

Durante o desenvolvimento, pratiquei variáveis, estruturas condicionais (`if`, `elif`, `else`), laços de repetição (`for`), métodos de strings e lógica de programação.

## ⚠️ Observação

Este projeto é educativo. A pontuação não garante que uma senha seja realmente segura. Não utilize senhas pessoais reais nos testes.
